# Analyze Sample Data Project

This project analyzes sample data using Python. It includes a Jupyter Notebook (`ex0.ipynb`) for visualizing data and performing analysis.

## Prerequisites

Ensure you have the following installed on your system:
- Python 3.8 or higher
- pip (Python package manager)
- Jupyter Notebook or JupyterLab

## Setup Instructions

1. Clone the repository or download the project files.
2. Navigate to the project directory:
   ```sh
    cd /path/to/project
    ```
3. setup the environment and install the dependencies

   ```sh
   conda create --name analyze_sample_data python=3.8 -y
   conda activate analyze_sample_data
   ```

4. install the required dependencies
    ```sh
    pip install -r requirements.txt
    ```

5. Start the Jupyter Notebook server:
    ```sh
    jupyter notebook
    ```

## Data Files
* `data/Hotel Reservations.csv`: Contains sample data for analysis.

* `data/upb.npy`: Additional data file used in the project.

## Notes
Ensure the data files are in the data/ directory for the notebook to work correctly.
Modify the notebook or script as needed for your specific analysis.
